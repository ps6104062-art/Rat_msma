# 🔥 Account Panel Bot

Telegram-бот для управления аккаунтами + скупка с tronaccs.market

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Переменные окружения (или отредактируй `config.py`):

```env
BOT_TOKEN=токен_от_@BotFather
ADMIN_IDS=твой_telegram_id
API_ID=твой_api_id       # my.telegram.org
API_HASH=твой_api_hash   # my.telegram.org
```

## Запуск

```bash
python bot.py
```

## Функционал

### 📱 Управление аккаунтами
- Добавление через авторизацию (номер → код → 2FA)
- Работа с 1 аккаунтом или сразу со всеми

### Действия с аккаунтом:
- 🗑 **Очистить чаты** — выход из групп/каналов, удаление личных диалогов
- 👥 **Очистить контакты** — удаление всех контактов
- 🔒 **Кикнуть сессии** — завершить все активные сессии
- 🤖 **Удалить из ботов** — заблокировать всех ботов
- 💾 **Скачать сессию** — получить .session файл
- 🔑 **Поставить пароль** — установить 2FA
- 📲 **Получить код** — запросить код (только для 1 аккаунта)

### 🛒 Скупка с tronaccs.market
- Фильтры: цена, страна, premium, спамблок, возраст, контакты
- Покупка одного или всех найденных аккаунтов
- История покупок

## Структура

```
├── bot.py              # Точка входа
├── config.py           # Конфиг
├── handlers.py         # Все хендлеры
├── keyboards.py        # Клавиатуры
├── texts.py            # Тексты
├── states.py           # FSM состояния
├── database.py         # SQLite
├── account_manager.py  # Pyrogram действия
├── tronaccs_api.py     # API клиент
└── sessions/           # Файлы сессий
```
